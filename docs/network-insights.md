# WLAN and LAN insights

Summary is the default for WLAN/LAN, with stable interface selectors, current-state cards and
progressive details. Table/Tree/Graph/raw evidence remain accessible. Missing observations stay
unknown; imported evidence is historical. Existing primary probe IDs/commands remain unchanged.
Optional schema-1 networkEvidence retains exact command/output/exit/timestamp/truncation plus
not-started omissions. Each network group has a 12-second elapsed / 256 KiB aggregate budget; SSH
exec/clock work shares three slots. Cached PHY/version data keeps its original acquisition time and
is invalidated on generation/topology/reset or explicit capability refresh.
