# RC7 qualification sign-off

RC7 retains the RC5 application, companion and helper behavior. Its changes repair hosted CI
startup, give each GNOME job private 1-GiB shared memory, and improve bounded diagnostic retention.
The original seven-case matrix, native workload, geometry/continuity assertions and production
sandbox behavior remain unchanged. No geometry fix or additional qualification privilege is added.

The diagnostic correction at `ba157af536d2f413a9f67d9215eb1ead8d081fcb` passed
[Linux/GNOME](https://github.com/brucerry/embedded-linux-diagnostic-hub/actions/runs/38162413764),
[Windows](https://github.com/brucerry/embedded-linux-diagnostic-hub/actions/runs/38162413755) and
[website](https://github.com/brucerry/embedded-linux-diagnostic-hub/actions/runs/38162413982)
checks. All seven GNOME 42/46/48/50 cases passed their original native and software SSH/PTY/live
collection/testing continuity checks. GNOME 42 Wayland passed 100 native cycles, 100 interrupted
cycles, 400 resize requests, exact 1100-by-760 saved bounds and 411 balanced effects with none
remaining. Its 42 ordered PTY ticks retained the same PTY, one connection and one terminal channel.
Its retained 13,534 protocol rows have no dropped rows, truncated partial lines or pending
remainder.

- Full local GNOME 42 controls used the retained immutable RC5 application and companion, whose
  product code is unchanged. Both traced and representative untraced controls passed the original
  full workload and continuity; they are not relabeled as RC7 assets. The exact proposed public
  diagnostics also passed without the private task-only callback observer.
- A genuine resize to 1180 by 760, compared with the 1100 by 760 native control, was rejected by the
  unchanged saved-normal equality assertion. No negative injection or private observer is shipped.
- Earlier RC5/RC6 hosted failures remain retained. The previous resource correction's hosted GNOME
  42 Wayland failure restored 1456 by 812 instead of 1100 by 760 despite ample shared memory. A
  later passing local trace exposed a clipped native-only maximized frame before effect attribution;
  Mutter's buffer/geometry handling is consistent with a possible consequence, but the final failure
  cause is unproven. The current hosted trace retained the expected native and effect frames.
- Tracing can change scheduling. Finite traced/untraced non-recurrence does not establish a cure for
  the GNOME 42/48 bounds history or GNOME 50 original concurrent-load/cycle31 failures. Proceeding
  is within the accepted finite isolated software scope; a new release-gate failure must be assessed
  independently. Physical GPU/display/device and higher GNOME 50 native resource-scale gaps remain.

RC5 and RC6 release workflows failed and published no release. Their tags and the public RC4 tag
remain immutable. The annotated `v0.2.0-rc.7` tag identifies the new version and this sign-off; its
publication requires its own complete hosted matrix and rebuilt assets with matching tag/commit,
version manifests and checksums. Windows signing status comes from that build's manifest. No local
RC7 package build is claimed because the four-GiB build reserve is unavailable. Cleanup deletion and
physical-device qualification are separate, unapproved actions.
