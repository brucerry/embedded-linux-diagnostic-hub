## Diagnostic Hub v0.2.0-rc.2

This preview adds an embedded **Terminal** to the desktop and website. It starts automatically on
the connected device's authenticated SSH session and remains available across tabs. ANSI, Unicode,
multiline shell syntax, interactive programs and terminal key bindings use the remote PTY. The
website requires the matching updated gateway and a proxy that forwards streaming responses.

Select text with a left-button drag, then right-click for Copy/Paste. The top-right copy button uses
the existing copy feedback. Ctrl+C copies a selection or interrupts the remote program; Ctrl+V
pastes. Clear terminal retains the current prompt/input and restores focus. Prompts receive a local
mint color when they have no remote color, and scrollback stays inside the fitted terminal. A pixel
duck and pig play ball beneath trees, with a tilted Earth rotating once per second behind the text.

Ending the outer shell with exit, logout where supported, or Ctrl+D automatically starts a fresh
shell on the same healthy SSH connection. Local history remains, queued input is discarded and no
commands are replayed. The new shell uses its default directory and environment. Recovery is
bounded; refused shells, transport failures and repeated rapid exits require a device reconnect.

Terminal history stays in bounded RAM and never enters diagnostic reports or update backups.
Five-second live collections use separate SSH exec channels, so their output and collected kernel
logs do not enter the terminal. Device broadcasts, login banners and background jobs that write
directly to the PTY remain visible, as in an ordinary SSH terminal.

Connection-form text selection no longer dismisses the form when a drag ends outside it. Direct
backdrop clicks still dismiss it. Fast diagnostic collections also finish a visible transfer
animation before returning to idle.

Automated coverage includes native and gateway transports, clipboard and keyboard interaction, shell
recovery, bounded queues, concurrent diagnostics and browser portability. Local qualification also
exercised Linux OpenSSH and Dropbear with Bash and BusyBox ash. Actual-board and clean-machine
acceptance remain separate; this is an engineering preview and Windows binaries may be unsigned.
