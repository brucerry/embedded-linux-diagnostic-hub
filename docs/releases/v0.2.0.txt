Description:
Diagnostic Hub v0.2.0 keeps the persistent in-place SSH terminal, device clock and diagnostics while returning Windows and Linux to standard native windows.
The reported OpenWrt Tests discovery error was not reproduced or repaired; its retired live entry point is removed. Local Windows/browser checks supplement required hosted OS gates. Physical boards and GPU/display configurations remain outside this software qualification.

Changes:
- Remove the Tests workspace and its desktop/gateway/SSH discovery, execution and test-report controls; preserve saved reports.
- Remove Genie runtime, native hooks, taskbar helpers and companion setup/delivery. Keep application data, desktop launcher and updater identities; scope the Linux window class/app ID to avoid the installed legacy extension's exact match.
- Keep the in-place terminal, device clock and later scrollbar/session fixes. The redundant Report & Evidence page remains absent.
- Preserve Windows and all seven existing Linux compositor cases, adapting gates to native windows, terminal continuity, responsiveness and crashes.
- Use exact-tag release names and four-section notes with all commits since the prior published release.
